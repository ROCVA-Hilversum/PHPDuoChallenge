Start met PHP Logica 101

Kies met je duo één missie: Eiland Escape, Snackbar Chaos of Heldenkeuring. Jullie hebben ongeveer twee uur. Maak eerst de verplichte stappen en daarna eventuele bonusmissies.

Voor de docent: vervang hieronder JOUW-GITHUBNAAM/JOUW-REPO door de echte eigenaar en repositorynaam. Deel met studenten de aangewezen repo, fork of Classroom-repo.

  1. Gebruik de Git- en PHP-installatie van school. Open een terminal in de map waarin je de opdracht wilt bewaren.
  2. Clone de repository. Kopieer de onderstaande regels één voor één:
git clone https://github.com/JOUW-GITHUBNAAM/JOUW-REPO.git php-logica-missies
cd php-logica-missies
php -S localhost:8000

Open http://localhost:8000/instructie.html in je browser en kies één missie. Laat de terminal open; stop de server met Ctrl+C.

Bewerk het start.php van je missie in je editor, sla op en vernieuw de browser. Herstel voor elke test de beginwaarden uit het testplan.

Zonder Git: open de repository op GitHub, kies Code → Download ZIP, pak de ZIP uit en open een terminal in de uitgepakte map met de README. Voer daar php -S localhost:8000 uit.

GitHub Pages voert geen PHP uit. De site toont de instructies. De PHP-uitvoer bekijk je via je lokale server. Dubbelklikken op PHP werkt niet; een PHP-link op Pages kan broncode tonen of een bestand downloaden.

Problemen? Bij “php wordt niet herkend”: gebruik de schoolinstructie voor PHP/XAMPP. Bij een bezette poort: gebruik php -S localhost:8001 en open http://localhost:8001/instructie.html. Bij “map bestaat al”: kies een andere lokale mapnaam of gebruik je bestaande kopie.

Inleveren: het gekozen start.php, bijbehorende testplan.md en terugblik.md, volgens de afspraak van de docent. Werk in één gedeelde versie en wissel elke vijftien minuten van rol.
