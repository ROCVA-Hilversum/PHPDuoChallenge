# Optioneel GitHub Projects-bord

Dit bestand is een voorstel; er is geen online GitHub Project aangemaakt. De les werkt ook zonder bord. Laat de docent de GitHub-inrichting vooraf doen.

Gebruik vier kolommen: **Te doen → Bezig → Testen → Klaar**.

Maak per duo deze kaarten, met de duonaam en gekozen missie in de titel:

1. **Keuze en plan** — namen, rollen en vier spelregels in eigen woorden.
2. **Invoer en arrays** — invoer zichtbaar, vaste arrayposities gebruikt.
3. **Vier controles** — afzonderlijke afwijsredenen en één eindoordeel.
4. **Testen en repareren** — acht gegeven tests en twee eigen tests vastleggen.
5. **Terugblik en inleveren** — rollen, uitleg en bestanden compleet.
6. **Bonus** — optioneel; eerst de basis afronden.

Verplaats een kaart pas naar Klaar als de navigator de uitkomst heeft gecontroleerd. Een kaart kan terug van Testen naar Bezig als een test faalt.

Voor Classroom: gebruik één groepsopdracht met deze repo als template en duo's van twee. Zonder Classroom: laat elk duo één fork delen en spreek een inleverplek af. Geef geen verplichte Git-instructie tijdens deze twee uur als studenten Git nog niet kennen.
