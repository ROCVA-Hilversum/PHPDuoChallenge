Je operatorenkaart

Een operator is een teken dat iets doet met waarden. Een vergelijking levert true (waar) of false (onwaar) op. Schrijf die woorden zonder aanhalingstekens.

TekenBetekenisVoorbeeld
=Een waarde opslaan$punten = 10;
+ - *Optellen, aftrekken, vermenigvuldigen$punten + 5
.Tekst en een waarde verbindenecho "Punten: " . $punten;
> <Groter / kleiner dan, zonder de grens$punten < 10
>= <=Groter / kleiner dan of gelijk aan, mét de grens$punten >= 10
=== !==Exact gelijk / niet exact gelijk; waarde én type$kleur === "groen"
&&EN: beide voorwaarden zijn waar$kaartjeGeldig && $deurOpen
||OF: minstens één is waar; beide mag ook$heeftPas || $heeftTicket
!NIET: keert waar en onwaar om!$deurOpen
== !=Vergelijken met typeomzetting (bonus)"7" == 7 is waar; "7" === 7 is onwaar.
/ % +=Delen, rest bij gehele deling, verhogen (bonus)7 % 2 is 1; $punten += 5; verhoogt met 5.

Let op: = geeft een waarde. Het is geen vergelijking. Gebruik bij tekstcontroles === of !==. Schrijf beide kanten van OF volledig: $kleur === "rood" || $kleur === "blauw".

Syntaxhulp: een losse controle
$leeftijd = 11;

if ($leeftijd < 12) {
    echo "Deze film is voor 12 jaar en ouder.<br>";
}

Vertaal dit bioscoopvoorbeeld zelf naar jullie missie.

Syntaxhulp: één keuze met twee uitkomsten
if ($deurOpen) {
    echo "De deur is open.";
} else {
    echo "De deur is dicht.";
}

Dit werkt als $deurOpen een boolean is: true of false. Gebruik voor tekst een echte vergelijking, zoals $deur === "open".
